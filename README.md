## 🌐 Available Platforms

DocGenie is built to meet you where you work. The ecosystem spans across four dedicated platforms:

* 🖥️ **CLI (Command Line Interface):** Fast, local terminal tool that respects `.gitignore` and securely transmits code chunks to the core API without leaving your terminal.
* 🧩 **VS Code Extension:** Integrated directly into your IDE for context-aware, file-specific documentation generation while you code.
* 💻 **Web Dashboard:** A powerful, browser-based control center to manage projects, input Git URLs, view analytics, and configure your AI tokens.
* 📱 **Android App:** A mobile companion application to monitor generation tasks, review architectural insights, and manage project states on the go.

## 📖 About DocGenie

DocGenie solves the scale and security problems of AI code documentation. By utilizing a "Bring Your Own Key" (BYOK) architecture and a secure asynchronous streaming proxy, it ingests massive local or cloud repositories and pipes them directly to Google AI Studio. 

* **Zero Token Markup:** You use your own API key.
* **Zero Code Storage:** Your codebase is streamed to the AI and immediately dropped from memory.
* **Instant Architecture:** Generates high-level block diagrams (Mermaid.js), API contracts, and low-level system docs.
